# Pokélistillos

¡Bienvenido a Pokélistillos.com! 🎮  
Una web creada para poner a prueba tus conocimientos sobre el mundo Pokémon de forma divertida, visual y competitiva.

## 🌟 ¿Qué es Pokélistillos?

Pokélistillos es un juego web donde los usuarios deben adivinar nombres de Pokémon a partir de pistas, siluetas o imágenes pixeladas. Cuanto más rápido aciertes, ¡mayor puntuación obtendrás!

Ideal para entrenadores nostálgicos y nuevos fans que quieren pasar un buen rato y picarse con amigos.

## 👾 Tecnologías utilizadas

- Angular 17
- NestJS (backend)
- PostgreSQL (base de datos)
- Prisma ORM
- Cloudinary (gestión de imágenes)
- Vercel + Railway (deploy)
